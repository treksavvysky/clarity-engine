# Packet Examples

This folder holds reference manifests that conform to `pcp_lite.schema.json`.

- `context_packet_example.json` is the canonical Stage 0 manifest used in tests and CI for compose/lint flows.
- `raw_intent_packet_example.json` is the canonical valid Raw Intent Packet.
- `raw_intent_packet_invalid_*.json` are focused validation fixtures.

Keep examples minimal, deterministic, and aligned with their corresponding
schema and documentation.
