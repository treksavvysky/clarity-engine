# Documentation Overview

This directory holds narrative and reference documentation for Clarity Engine.

- `CLARITY_ENGINE_OVERVIEW.md` defines the Clarity Engine's role in the cognition ecosystem and its core function: raw intent to bounded mission packet.
- `compose_packet_explained.md` captures how packet manifests are transformed into the rendered packets and hashes.
- `INTENT_CAPTURE_GUIDE.md` gives the human-side best practices for capturing raw intent so the Clarity Engine has enough signal to clarify.
- `vision/` contains the long-lived mission and staged roadmap artifacts (Stage 0 references, Stage-01 mission and summary).

Stage 0 is currently frozen; update docs here when scoped behavior or staged plans change.
